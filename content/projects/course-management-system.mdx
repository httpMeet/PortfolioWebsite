# Course Management System

## System Overview

Course Management System is a web application for managing courses, student enrollments, and academic grades.

### Problem
Tracking courses, student enrollments, and grades in spreadsheets leads to duplicated and inconsistent records.

### Solution
Developed a web application with distinct access roles for Admins, Instructors, and Students to manage academic records.

---

## Technical Highlights

- **Access Controls**: Created role-based page navigation for Admin, Instructor, and Student access levels.
- **Seat Limit Verification**: Added course enrollment capacity checks before confirming student registrations.
- **AJAX Interactions**: Used AJAX requests for dynamic dropdown updates during course selection.
