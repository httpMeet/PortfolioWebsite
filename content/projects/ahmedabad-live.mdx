# Ahmedabad Live

## System Overview

Ahmedabad Live is a city information website presenting local news updates, event listings, and directory entries.

### Problem
Local news updates and city event notices are distributed across multiple unorganized platforms.

### Solution
Created a web application with category filtering for local news, events, and business directory listings.

---

## Technical Highlights

- **Article Views**: Built news article creation and category filtering views in PHP.
- **Search Filtering**: Added keyword search filtering for news articles and business directory entries.
- **Admin Management**: Created an admin dashboard for publishing articles and managing event listings.
